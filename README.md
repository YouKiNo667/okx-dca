# OKX 定投记录工具

一个本地运行的定投记账工具，专门为 OKX 用户设计：

- 读取你的 OKX 成交流水、持仓余额
- 自动抓取行情，计算总投入/当前市值/累计收益/真实年化(XIRR)
- 图表展示投入与回收走势、持仓构成
- 流水增删改查、手动补录（OKX 账单 API 只保留近3个月）
- 零依赖：纯 Python 标准库，不用 pip install 任何东西

## 功能

- **四个指标卡**：总投入、当前市值、累计收益（+收益率）、真实年化（XIRR）
- **投入与回收走势**：双折线图，鼠标悬浮有十字线和明细
- **持仓构成 + 明细**：各币种市值占比；没行情的币可以手动填单价
- **流水增删改查**：编辑、删除、手动补录、备注
- **CSV 导出**、明暗主题、时间范围筛选（近30天/90天/1年/全部）

## 安装使用

### 前置要求

- Python 3.10+（3.14 测试通过）
- 能访问 OKX 的网络环境（国内需要代理）

### 快速开始

```bash
# 下载
git clone https://github.com/你的用户名/okx-dca.git
cd okx-dca

# 启动
python okx_dca.py
```

浏览器会自动打开 `http://127.0.0.1:8787`

### 配置 OKX API

1. OKX 网页版 → 用户中心 → API → 创建 V5 API 密钥
2. **权限只勾「读取」**（不勾交易、不勾提币）
3. 打开页面右上角「设置」，填入 API Key / Secret Key / Passphrase
4. 点「保存并测试连接」
5. 点「同步 OKX」拉数据

## 数据说明

- **数据文件**：`data.json`（流水、持仓、行情缓存）
- **密钥文件**：`config.json`（API 密钥、代理设置）
- **备份**：直接拷贝这两个文件即可
- **OKX 账单 API 只保留近3个月**，更早的定投用「手动记一笔」补录

## 网络配置

国内网络需要代理，在「设置」里填代理地址，例如：

- Clash/V2Ray 默认：`http://127.0.0.1:7890`
- 其他常见：`http://127.0.0.1:10809`
